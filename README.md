# Healthcare Operations & Financial Intelligence Dashboard

Power BI dashboard analysing 27,890 encounters, $101.51M claim cost, $31.10M payer coverage.

## KPIs
- Total Encounters: 27,890
- Total Claim Cost: 101.51M
- Total Payer Coverage: 31.10M
- Zero Coverage: 13,586 (48.7%)
- % Over 24h: 0.27% (76 encounters)

## Dashboard Pages
1. OVERVIEW - KPIs and slicers
2. TREND - Monthly trends
3. ENCOUNTER CLASS - Class breakdown
4. COST AND PAYER - Coverage gap analysis
5. PROCEDURES - CODE analysis
6. KPI DEFINITIONS - DAX measures logic

## Deliverables
- Power BI .pbix file
- Data Quality Assessment
- KPI Definitions
- Screenshots (6 pages)
- Validation Evidence
- Executive Summary + 3 Recommendations

Power BI Desktop, DAX, Power Query, Synthea dataset
